# Store screenshots

Eight phone screenshots at 1080 x 1920, 24-bit PNG without alpha.

They were rendered from the built app running in a desktop browser, with the invented sample data in `docs/sample-data.json` and the clock set to a Thursday morning. They show the real interface, but they are not captures from an Android device: there is no status bar, and device fonts and pickers can differ slightly.

Before publishing, retake them on your phone (import the sample data first with `npm run sample`, then Settings > Import a backup), or check each one against the phone and keep it only if it matches.

|---|---|
| `01-week-capacity.png` | The 168-hour ledger and buffer |
| `02-conflicts.png` | A shift landing on a study block, with fixes |
| `03-exam-hours-gap.png` | An exam behind pace, with the one-tap fix |
